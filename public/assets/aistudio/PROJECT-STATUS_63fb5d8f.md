## 1. What GWLite is

A DIY, driver-free clone of the GlassWire network monitor for Windows, built from scratch in this workspace. Scope decided with the user: **live per-app traffic graph, per-app attribution, hostnames, usage/quota tracking, alerts, 6 time ranges (5m/3h/24h/30d/custom/unlimited), light+dark themes — explicitly NO firewall, NO network scanner, NO resource monitor.**

Two UIs exist and both work:
1. **Web dashboard** (feature-complete: quotas, alerts bell, custom range) served by the collector at `http://127.0.0.1:8912/`
2. **Native Rust window** (primary, feature-complete: tabs, smooth GlassWire hills with
   auto-scale, drag-select breakdown, quota form, alerts, 6 ranges, per-app icons,
   light/AMOLED-dark themes, zoom, single-instance)

The user chose the Rust native UI as the going-forward dashboard (browser tab cost ~350–600 MB; Rust window keeps total footprint ~250 MB). The web dashboard remains as a fallback.

## 4. Architecture & data flow

```
ETW "NT Kernel Logger" (NetworkTCPIP keyword)
  └─ EtwNetworkCollector: parses RAW payloads per the Microsoft-Windows-Kernel-Network manifest
     (PID is payload field 0 — NOT the ETW header ProcessID; ids 10/11/42/43 = IPv4 tcp-send/recv,
      udp-send/recv; 26/27/58/59 = IPv6. Layout: PID u32, size u32, daddr, saddr, dport u16be, sport u16be)
  └─ FlowEvent(ts, pid, remote, port, proto, in, out)
     └─ TrafficWriter.OnEvent: drops self-PID + loopback → TrafficRing.Add
TrafficRing: per-second dict keyed (pid, host, port, proto); 300s in-memory history; late events folded in
Writer loop (1s): ring.AdvanceTo(now) → DrainClosed → per bucket:
  - resolve pid→path via ProcessTracker (refreshed every 2s); fallback TcpOwners snapshot
    (live TCP owner table) for phantom pids; dedup relay-copies (same 2nd, same remote:port, one resolved)
  - AppRegistry.GetOrCreate(path) → apps table (id = autoincrement; new apps fire Db.AppCreated → AlertEngine
    new-app event + icon extraction)
  - INSERT into traffic_1s
Aggregator loop (30s): tier rollups 1s→60s→3600s→86400s with watermarks in meta
  (rollup_60s_wm etc.; keyed unique indexes make re-runs idempotent) + prune (1s>48h, 60s>62d, 3600s>400d, daily forever)
HostResolver loop (30s): discovers hosts from traffic_1s (meta hosts_seen_wm watermark) → ClaimHost →
  reverse DNS (3 concurrent, 3s timeout, 1h cooldown per IP)
GeoIpJob loop (120s): OFF by default (meta geoip_enabled); when on: hosts without region → batch POST
  http://ip-api.com/batch (100/call) → countryCode → hosts.region; direct fails on this network →
  automatic curl retry via SOCKS proxy 127.0.0.1:10808 (temp-file body, 10-min backoff on total failure)
AlertEngine loop (60s): quota checks (75/90/100% of limit) → events table; dedup per (type, app, period)
  via EventExistsSince — survives restarts. Also new-app events (type 1).
API (Kestrel, 127.0.0.1:8912) + tray icon (STA thread) + shortcuts + second-instance guard
```

**Storage (SQLite WAL, page 4096, busy_timeout 5000):**
- `apps(id, path UNIQUE, name, publisher, icon BLOB, first_seen)` — icon = PNG extracted from exe
- `hosts(ip BLOB PK, hostname, region, first_seen, last_seen)`
- `traffic_1s/60s/3600s/86400s(ts, app_id, host BLOB, port, proto, inb, outb)` + ts/app indexes;
  rollup tiers have `UNIQUE(ts, app_id, host, port, proto)` (INSERT OR REPLACE = idempotent)
- `quotas(app_id NULL=global, period, limit_bytes)` UNIQUE(COALESCE(app_id,-1), period)
- `events(id PK AUTOINCREMENT, ts, type, app_id, data JSON)` — types: 1=new app, 2/3/4=quota 75/90/100%
- `meta(key, value)` — watermarks, events_seen_id, geoip_enabled
- Quota periods use **local time** (daily=midnight, weekly=Monday, monthly=1st) — `Periods.StartUtc`

**API (all verified):**
`/api/status` · `/api/live?seconds` · `/api/traffic?range=5m|3h|24h|30d|unlimited|custom&from&to&app_id&breakdown=apps`
(response shape: `{from,to,bucketSeconds,tier,data:{rows:[[ts,app_id,in,out]],appNames:{id:name}}}`) ·
`/api/apps?range&limit` · `/api/hosts?range&limit` (ip, hostname, region, inBytes, outBytes) ·
`/api/usage?period=today|week|month` · `/api/quotas` GET/POST/DELETE · `/api/events?limit` + `/api/events/seen` POST ·
`/api/icon?app_id` (PNG, cached) · `/api/settings` GET/POST `{geoip:bool}`

## 5. Hard-won technical facts (do not relearn these)

1. **Kernel-Network PID is payload field 0**, not the ETW header ProcessID. Parsing the header gives phantom PIDs on some flows.
2. **TraceEvent 3.1.30 API drift:** `TraceEventSession` lives in `Microsoft.Diagnostics.Tracing.Session`; `KernelTraceEventParser` in `Microsoft.Diagnostics.Tracing.Parsers`; event classes expose `TimeStamp`/`ProcessID` (no `TimeStampUtc`/`PID`); IPv6 classes already expose `IPAddress` typed addrs. `ETWTraceEventSource(session, TraceEventSourceType.Session)` + `source.Kernel.TcpIpSend += …` etc.
3. **Kernel session name** = `KernelTraceEventParser.KernelSessionName`; enable with `Keywords.NetworkTCPIP`. Requires elevation; only one NT Kernel Logger at a time.
4. **PROCESSENTRY32W.pcPriClassBase is a 32-bit LONG** (not IntPtr) — wrong size = ERROR_BAD_LENGTH 24 in Process32FirstW.
5. **Microsoft.Data.Sqlite connection is shared across threads** in this design → every Db public method is wrapped in `lock (_gate)`.
6. **The service's SQLite/SQL/API strings are runtime-obfuscated** (real GlassWire does this too) — static string grep proves nothing about missing features.
7. **Transparent proxy (WireSock/v2rayN) relays** some flows: duplicate events with a PID that belongs to no live process. Handled: owner-table fallback + same-second relay-copy dedup; leftovers recorded as `unknown:pidN` apps so bytes are never lost. Inherent limitation without a WFP driver.
8. **Attribution accuracy verified**: controlled downloads matched per-app byte counts exactly (payload-level); NIC diff within expected overhead.
9. **egui_plot 0.29**: `x_axis_formatter/y_axis_formatter` take 2-arg closures `(GridMark, &RangeInclusive<f64>)`; `Line::new(points).name(...)`; `PlotUi` has `line()` not `lines()`; no `set_plot_bounds_y`, no `suggest_best_fit`, no `set_plot_bg_color` on PlotUi, no `opacity()` on Line (use `.color(Theme::alpha(...))`).
10. **egui default fonts lack ● ↑ ↓ ☀ ☾ glyphs** → `install_fonts()` loads `segoeui.ttf` + `seguisym.ttf` from C:\Windows\Fonts. Emoji flags render as tofu in egui — use text badges (region code) instead.
11. **egui_plot 0.29's axis-label rendering is unreliable for our use case** — the v2 approach silences built-in labels (empty formatter strings) and draws a custom overlay (tick labels + horizontal grid lines) via `presp.transform.position_from_point(&PlotPoint::new(x,y))` after `plot.show()`. This partially works; see §7 known issues.
12. **Web asset cache-busting**: bump `?v=N` in `wwwroot/index.html` on every app.js/styles.css edit; and `wwwroot` changes only reach the served output dir after `dotnet build` (csproj copies wwwroot → output; ContentRoot = AppContext.BaseDirectory).
13. **TFM is net8.0-windows** → output dir is `bin\Release\net8.0-windows\`. Always launch that one.
14. `gwlite.exe` with no args = serve mode (tray + API). `--smoke` = phase-1 console test. Second instance while one is serving → prints notice, opens dashboard, exits 0.

## 13. Console-window fixes (2026-10-28 21:10)

User reported: (a) the app "doesn't work without the cmd window open", (b) random cmd
windows flashing open/closing. Three causes, all fixed and verified:
1. **gwlite-ui.exe was a console-subsystem binary** — Windows attached a cmd window to it;
   closing that window killed the UI. Fix: `#![cfg_attr(not(debug_assertions),
   windows_subsystem = "windows")]` at the top of main.rs (release = GUI subsystem, debug
   keeps the console). Verified: PE header subsystem = 2 (GUI); full-screen capture shows
   no console; UI auto-opened by the collector task runs windowless.
2. **GeoIpJob spawned curl with no CreateNoWindow** — from a GUI parent, curl allocated its
   own console → the periodic flash. Fix: `CreateNoWindow = true`.
3. **OpenDashboard started the UI/Edge with UseShellExecute=false** (.NET Core default) —
   also granted the child a fresh console. Fix: UseShellExecute = true for the UI exe,
   Edge --app, and URL fallback launches. (The two PowerShell spawns already had
   CreateNoWindow.)

Restarted the collector via `schtasks /run /tn GWLite` after rebuild: log shows clean
startup, ETW live, UI auto-opened with no console anywhere.
